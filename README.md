# احاديثي

تطبيق ويب بسيط لعرض أحاديث نبوية شريفة من صحيح البخاري بشكل عشوائي.

## نظرة عامة

موقع "احاديثي" هو تطبيق ويب خفيف يعرض حديثاً نبوياً عشوائياً من صحيح الإمام البخاري في كل مرة. يتيح للمستخدم التنقل بين الأحاديث بضغطة زر واحدة.

## المميزات

- عرض أحاديث عشوائية من صحيح البخاري
- واجهة مستخدم بسيطة وأنيقة بتصميم إسلامي
- دعم كامل للغة العربية
- تصميم متجاوب يعمل على جميع الأجهزة
- خط عربي جميل (Amiri)

## التقنيات المستخدمة

- **HTML5** - لهيكلة الصفحة
- **CSS3** - لتنسيق وتصميم الواجهة
- **JavaScript** - لجلب وعرض الأحاديث بشكل ديناميكي

## مصدر البيانات

يتم جلب الأحاديث من واجهة برمجة التطبيقات (API) المفتوحة المتاحة عبر:
```
https://cdn.jsdelivr.net/gh/fawazahmed0/hadith-api@1/editions/ara-bukhari.json
```

## كيفية التشغيل

1. قم بفتح ملف `index.html` في أي متصفح حديث
2. سيظهر لك حديث عشوائي تلقائياً
3. اضغط على زر "التالي" لعرض حديث آخر
